GitHub वर नवीन repository तयार करा. या पाचही फाइल्स repository च्या मुख्य भागात (root) upload करा.
Settings > Pages > Deploy from a branch > main > /(root) निवडा.
काही मिनिटांनी GitHub Pages ची लिंक उघडा.

Android वर:
- लिंक Chrome मध्ये उघडा.
- Menu मधून "Add to Home screen" / "Install app" निवडा.
- अॅपमध्ये नोंदी IndexedDB मध्ये या डिव्हाइसवर साठवल्या जातात.
- Backup Export नियमित करा. Browser data clear केल्यास स्थानिक माहिती पुसली जाऊ शकते.

V1 मधील विभाग:
- Money Manager: हाताने उत्पन्न/खर्च नोंदवणे (बँक कनेक्शन नाही)
- Dream Tracker: ध्येय आणि 0–100% प्रगती
- Daily Command: तारीख असलेली कामे आणि पूर्ण/अपूर्ण स्थिती
- Knowledge Vault: शीर्षक आणि मजकूर असलेल्या नोट्स
- JSON Backup Export/Import
- Marathi/English UI switch
